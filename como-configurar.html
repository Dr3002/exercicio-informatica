📋 Como configurar o Google Sheets

Siga estes passos para conectar sua planilha ao site. Leva menos de 10 minutos!

1

Crie a planilha no Google Sheets

Acesse sheets.google.com e crie uma nova planilha em branco.

Na primeira linha, adicione exatamente estes cabeçalhos (em minúsculas):

modulonomeiconedescricaotipoperguntaopcoesrespostaexplicacao
← copie esses nomes exatamente como estão →
2

Entenda cada coluna

ColunaO que colocarExemplo
moduloID único do módulo (sem espaços)logica
nomeNome bonito do móduloLógica de Programação
iconeEmoji do módulo🧩
descricaoDescrição curtaAlgoritmos e sequências
tipomc múltipla escolha  tf verdadeiro/falso  gap lacunamc
perguntaTexto da pergunta. Para gap use ___ no lugar da lacunaO ___ é o cérebro do PC.
opcoesSó para mc: opções separadas por |Monitor|CPU|Teclado|Mouse
respostamc: número da opção correta (0 = primeira) · tf: true ou false · gap: texto esperado1
explicacaoMensagem exibida após responder (opcional)A CPU processa tudo!
3

Exemplo de linhas prontas

Copie essas linhas como ponto de partida:

modulonomeiconedescricaotipoperguntaopcoesrespostaexplicacao
logicaLógica🧩AlgoritmosmcO que é um algoritmo?Vírus|Passos para resolver um problema|Jogo|Planilha1Algoritmo = sequência de passos!
logicaLógica🧩AlgoritmostfTodo computador precisa de um sistema operacional.trueSem SO o PC não funciona!
windowsWindows🪟Sistema operacionalgapPara copiar usamos ___ e para colar ___.Ctrl+C|Ctrl+VCtrl+C copia e Ctrl+V cola!
💡 Para gap com múltiplas lacunas, separe as respostas por | na mesma ordem das lacunas.
4

Publique a planilha na web

No Google Sheets, clique em Arquivo → Compartilhar → Publicar na web.

Em "Toda a planilha", selecione o formato Valores separados por vírgula (.csv) e clique em Publicar. Confirme clicando em OK.

Isso torna os dados acessíveis publicamente (apenas leitura). Não compartilhe dados sensíveis dos alunos aqui.

5

Copie o ID da planilha

Na URL do Google Sheets, o ID fica entre /d/ e /edit:

https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit

Copie apenas a parte destacada em amarelo (é um código longo com letras e números).

6

Cole o ID no arquivo index.html

Abra o arquivo index.html em um editor de texto (Bloco de Notas serve). Procure a linha:

const SHEET_ID = 'SEU_ID_AQUI';

Substitua SEU_ID_AQUI pelo ID copiado no passo anterior. Salve o arquivo e publique no GitHub Pages.

🔄 A partir daí, basta editar a planilha para adicionar ou modificar exercícios. O site atualiza automaticamente!
7

Pronto! Publique no GitHub Pages

Faça upload do index.html e deste como-configurar.html no seu repositório GitHub.

Ative o GitHub Pages em Settings → Pages → Branch: main e compartilhe o link com seus alunos! 🎉
